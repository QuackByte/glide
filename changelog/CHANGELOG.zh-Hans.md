# 更新日志

这里记录了 Glide for Mac 每个版本的新变化。Glide 会在更新后显示一次新增的条目，GitHub 上每个版本的说明也来自这里，所以请以 Glide 用户的角度来写。本文件是 CHANGELOG.md 的译文，CHANGELOG.md 才是原文。每次发布前，请在下一个版本下为每项值得了解的改动添加一条记录。

## 0.10.2 — 2026-10-19

### 新增

- **平铺布局：⌃⌥↑ 和 ⌃⌥↓ 先切换标签。** 在标签组中，它们先切换标签，然后才移动到该方向的平铺块。

### 修复

- **平铺布局：相邻的平铺块会缩小以适应应用的最小宽度。** 当应用有最小宽度时，旁边的平铺块会缩小以容纳它，而不是重叠，并且 Glide 会说明为什么调整大小会在该宽度处停止。

## 0.10.1 — 2026-10-19

### 修复

- **平铺布局中的标签组可以正常使用。** ⌃⌥[ 和 ⌃⌥] 可以把窗口加入标签组（即带标签的列），也可以把一个标签移出，单独占一个平铺块，滚动布局中此前已可如此操作。

## 0.10.0 — 2026-10-19

### 新增

- **平铺现在是螺旋布局。** 按 ⌃⌥T 可将工作区切换为所有窗口都能放进屏幕的布局：一个窗口占满屏幕，两个窗口各占一半，从第三个窗口起，最后一列会再次拆分，上下与左右交替。它使用 2 列，或使用新增的 ⌃⌥G 切换为 3 列，在超宽显示器上 Glide 也会选择 3 列。切换回滚动后，窗口的顺序保持不变。
- **按方向在平铺工作区中移动。** ⌃⌥ + 方向键可聚焦到当前平铺块旁边的平铺块，⌃⌥⇧ + 方向键可与相邻的平铺块交换位置。循环切换宽度（⌃⌥R）会改变当前平铺块与其后平铺块分配空间的方式，而 ⌃⌥F 可将某个平铺块放大到占满屏幕，直到你再次按下。
- **选择平铺工作区使用的列数**，位于“设置 › 通用 › 平铺列数”：自动（超宽显示器上为 3 列，否则为 2 列）、2 或 3。

### 变更

- **将窗口发送到另一个工作区时，只会移动该窗口。** ⌃⌥⇧1…9 和 ⌃⌥⇧PgUp/PgDn 以前会带走整列，现在只有当前聚焦的窗口会作为单独的一列移走，而你仍停留在当前工作区。

## 0.9.4 — 2026-10-19

### 修复

- **关闭窗口后不再留下空隙。** 当窗口关闭或离开时，忽略部分移动的应用（例如 Proton Mail）可能留在原处，造成空隙。现在 Glide 会检查窗口实际所在的位置，并将其摆正。

## 0.9.3 — 2026-10-19

### 新增

- **平铺布局。** 按 ⌃⌥T 可将当前工作区在滚动条带和平铺布局之间切换。在平铺布局中，所有列共享屏幕，无需滚动即可全部显示。每个工作区都会保留自己的布局，即使重启 Glide 也不例外。循环切换列宽（⌃⌥R）可让某一列占据更大或更小的份额，拖动其边缘可调整大小，而 ⌃⌥F 仍可让它保持全宽，直到你再次按下。
- **选择新工作区的初始布局**，位于“设置 › 通用 › 布局”：滚动（和以前一样）或平铺。已用 ⌃⌥T 切换过的工作区会保留各自的布局。

## 0.9.2 — 2026-10-16

### 新增

- **“新功能”也支持你的语言了。** Glide 在更新后显示的说明，以及“新功能”中的内容，现在与 Glide 的其余部分使用相同的语言。

## 0.9.1 — 2026-10-16

### 新增

- **Glide 支持你的语言。** 除英语和西班牙语外，Glide 现在还有法语、德语、日语、简体中文、韩语和巴西葡萄牙语版本，并会跟随 macOS 的首选语言。

## 0.9.0 — 2026-10-15

Glide for Mac 现在与 Glide for Windows 使用相同的版本号。

### 新增

- **所有快捷键集中在一页。** 按 ⌃⌥/ 即可查看全部快捷键；再按一次、按 Esc 或点按外部即可关闭。菜单栏菜单中“快捷键”的顶部也有此项。
- **报告问题…**，位于菜单栏菜单和“设置 › 通用”中。Glide 会把最近的日志和设置（已去除窗口标题）打包成 zip，在 Finder 中显示，并在 GitHub 上为你打开一个新的 issue，供你描述发生了什么并附上该 zip。不会自动发送任何内容。
- **Glide 会说西班牙语。** 当 macOS 使用西班牙语时，Glide 也会使用西班牙语。“新功能”仍为英语。

### 修复

- **全屏就保持全屏。** 你设为全屏的窗口，或是占满显示器的视频或游戏，不会再被拉回它所在的列。Glide 不再干预它：会在其上隐藏焦点环、调暗效果和标签页栏，并让水平滚轮和三指轻扫在该显示器上直接作用于它。退出全屏后，它会回到原来的列。

## 0.4.0 — 2026-10-14

### 新增

- **拖动窗口时预览落点。** 拖动窗口时，会以焦点环的颜色显示一个轮廓，指出它将加入哪一列（包括标签页栏）。拖到另一台显示器上时，会用一条横杠表示它将插入该显示器哪两列之间。没有高亮则表示窗口会弹回原位。

## 0.3.0 — 2026-10-14

### 新增

- **每台显示器都会平铺。** 每台显示器都有自己的条带和九个工作区。快捷键作用于带有聚焦窗口的显示器，或指针所在的显示器。⌃⌥⌘←/→ 将焦点移到该侧的显示器，⌃⌥⌘⇧←/→ 将聚焦的列送到那里。新窗口会加入其打开时所在的显示器。
- **把窗口拖到想放的位置。** 放到标签页栏上，它就成为那里的一个标签页；放到另一个窗口上，它会堆叠进该窗口所在的列；放到另一台显示器上，它会加入那台显示器的条带。把浮动窗口放到某个平铺窗口上，它会加入平铺。放在其他位置，则会像以前一样弹回原位。
- **鼠标滚轮可滑动条带。** 倾斜滚轮（或使用拇指滚轮）即可沿条带移动，也可以在滚动时按住 ⌃⌥。在“设置 › 鼠标水平滚轮”中选择何时启用倾斜滚动：始终、使用 ⌃⌥ 或关闭。
- **应用在你常用的位置重新打开。** Glide 会记住每个应用所在的显示器、工作区、列宽和在条带上的位置，并让它的新窗口在那里打开。你可以在“设置”中将其关闭，或忘记所有位置。
- **焦点环粗细**，可在“设置 › 外观”中设为 1 到 12 点。

## 0.2.1 — 2026-10-14

### 新增

- **新功能。** 更新后，Glide 会显示有哪些变化。之后可在菜单栏的 **新功能** 中再次查看。

## 0.2.0 — 2026-10-14

### 新增

- **Glide 会自动保持最新。** 它每天检查一次是否有新版本并提示你；如果你在“设置 › 更新”中开启了自动安装，它会替你安装。菜单中的 **检查更新…** 会立即检查。每个更新都经过 Apple 的签名和公证。
- **Glide 是开源的**，采用 MIT 许可证：[github.com/QuackByte/glide](https://github.com/QuackByte/glide)。

## 0.1.1 — 2026-10-13

### 修复

- 退出并重新打开 Chrome、T3 Code 或其他 Chromium 或 Electron 应用后，焦点会停留在之前的窗口上，而新窗口则在屏幕之外。现在新窗口会获得焦点并滚动到视野内。

## 0.1.0 — 2026-10-13

Glide for Mac 的首个版本。

- **滚动条带上的列**：⅓、½、⅔ 和全宽，堆叠，以及标签页列，所有操作都有对应的快捷键。
- **九个工作区**、带实时预览的概览、三指轻扫、焦点环、应用规则，以及一个看门狗：Glide 崩溃时，它会把你的窗口放回原位。
